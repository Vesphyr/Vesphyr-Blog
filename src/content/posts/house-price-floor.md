知乎上有个问题叫「房价最终会降到什么地步」，底下有一份做得很细的回答：用冰山数据的二手成交价打底，叠上统计局 70 城、日美港的历史泡沫类比和租金回报率，推了两种情景。数据截止 2026-10-18，作者在 11 月初更新到 V2。

下面把里面的主要结论和推演方法整理一遍。数字都来自那份回答，属于非官方口径。

## 现在跌到哪了

先看已经发生的回撤。同一轮下跌，不同口径能差出二十个百分点：

| 口径                         | 一线       | 二线       | 三四线     |
| ---------------------------- | ---------- | ---------- | ---------- |
| 统计局 70 城（官方口径）     | 约 -17%    | —          | —          |
| 冰山二手成交价（较高点回撤） | -34%～-43% | -40%～-51% | -45%～-54% |

环京这类靠投资客撑起来的盘更极端：廊坊、燕郊一带较高点已经跌了 70%～75%。

最新的二手成交均价大致是这样（元/平方米）：

| 城市         | 均价      |
| ------------ | --------- |
| 上海         | 约 4.4 万 |
| 北京、深圳   | 约 4.3 万 |
| 杭州         | 2.4 万    |
| 广州         | 2.1 万    |
| 南京         | 1.6 万    |
| 苏州         | 1.5 万    |
| 成都         | 1.2 万    |
| 多数二线城市 | 1 万上下  |

统计局 70 城是官方口径，经过城市汇总，涨跌被平滑过；冰山用的是逐笔二手成交价。讨论「跌了多少」之前，先问一句是哪个口径，比争数字有用。

## 推演的三个支点

那份回答没有直接外推趋势，而是从三个方向夹逼：

**一、成交数据打底。** 冰山数据 45 城二手成交均价（截至 2026-10-18），加冰山指数（按小区最低挂牌价编制，2026-11-01）做核心区与郊区、分价段、分户型的拆分。另有两组逐笔数据用来校验：深圳 1.75 万笔（2025-04 至 2026-09）、北京 44.5 万笔做质量调整后的价格指数。统计局 70 城则提供 2015 年以来的一条长序列。

**二、外部数据交叉验证。** 中原地产城市指数、乐有家、贝壳网签、克而瑞各城市网签均价，以及券商、AMRO、高盛、Oxford Economics 对真实跌幅的测算。

**三、历史泡沫类比 + 估值锚。** 日本（不動産経済研究所的新建公寓均价、东京房价收入比）、香港（差饷署售价指数、中原城市领先指数）、美国（Case-Shiller），加上 1993 年海南。估值端用租金回报率与房价收入比，政策端记着 2026-09-29 的首套房贷贴息和 5 年期 LPR 3.5%。

## 两种情景

推演的落点不是一条曲线，而是两种情景下的区间：

| 情景 | 见底时间      | 一线       | 二线       | 普通三四线 |
| ---- | ------------- | ---------- | ---------- | ---------- |
| 基准 | 2029 年四季度 | -48%～-52% | -51%～-59% | -59%～-64% |
| 悲观 | 2034 年三季度 | -61%～-65% | —          | -71%～-74% |

悲观情景基本是照日本的路子走：见底时间拉长到 2034 年，三四线的跌幅接近日本地方城市的量级。回答里还提了一句更要紧的：投资型三四线的问题不是价格，而是有价无市——价格挂在那里，但卖不掉，流动性先没了。

## 读这份推演时该留意的三件事

**口径。** 前面那张表已经说明，统计局 70 城和冰山成交价之间差着 17 到 43 个百分点。任何关于「房价跌了多少」的结论，先看数据源是网签还是成交、是新房还是二手。

**情景不等于预测。** 基准情景 2029 年见底，前提是利率和政策按现在的路径走。贴息、LPR、土地供应任何一项变了，时间轴就得重画。作者自己在回答里也写了「凑合着看」。

**分级比总量有用。** 一线 -50% 和三四线 -60%，落在不同的资产上是两件事：一个是账面回撤，一个是卖不出去。判断风险时，城市层级和流动性要分开看。
